# keyframe-kit — بلجن لـ Claude Code (الإصدار 0.1.0)

ثلاث أدوات ميديا صغيرة تُشغَّل بسكربت لصنّاع الفيديو والريلز:

| الأداة (الـskill) | وش تسوي | تحتاج |
|---|---|---|
| `key-decontam` | تشيل الخلفية الخضراء من **رسومات مسطّحة بخطوط خارجية** (ملصقات، أغراض، شخصيات على شيت أخضر)، وتقصّ كل عنصر، وفيها **بوابة فحص** (`--check`) تعدّ البكسلات المائلة للأخضر المتبقية على حواف الـPNG. | numpy وOpenCV |
| `duck-curve` | تقرأ ملف صوت كلام WAV وتكتب قائمة JSON فيها **قيمة خفض موسيقى لكل فريم فيديو**: 1.0 وقت السكوت، وحوالي -11 ديسيبل تحت الكلام، نزول سريع وطلوع بطيء. | numpy |
| `blank-beats` | تكشف **الثواني شبه الفارغة في الفيديو** (ما فيه إلا لون الخلفية) وتطلع لك الفترات. | numpy وffmpeg |
| `keyframe-doctor` | تفحص الاعتماديات فوق وتطبع أمر التثبيت لأي شي ناقص. | - |

## المتطلبات (اقرأها أول)

البلجن نفسه سكربتات بايثون عادية، لكن أداتين تحتاجان برامج خارجية. ما يتثبّت لك شي تلقائياً.

| الاعتمادية | تستعملها | الرخصة | التثبيت |
|---|---|---|---|
| بايثون 3.8+ (مكتوب بصيغة 3.8 و**مُختبر على 3.14 فقط على ويندوز**) | الكل | PSF | python.org |
| numpy | الأدوات الثلاث | BSD-3-Clause | `python -m pip install numpy` |
| opencv-python-headless (أو opencv-python) | `key-decontam` | Apache-2.0 (والحزمة تضم FFmpeg بترخيص LGPL ومكتبات أخرى) | `python -m pip install opencv-python-headless` |
| ffmpeg على `PATH` | `blank-beats` | LGPL أو GPL **حسب النسخة اللي تثبّتها** | ويندوز `winget install Gyan.FFmpeg`، ماك `brew install ffmpeg`، ديبيان/أوبنتو `sudo apt install ffmpeg` |

ffmpeg يُشغَّل كبرنامج منفصل، والبلجن لا يضمّه ولا يربط به. إذا نقصت اعتمادية تقف الأداة بسطر واحد يسمّيها ويذكر أمر التثبيت (رمز الخروج 1، بلا traceback). قل لـClaude «شغّل keyframe-doctor» أو نفّذ:

```
python scripts/kk_doctor.py [--tool key_decontam|duck_curve|blank_beats]
```

`duck-curve` تحتاج numpy فقط (تقرأ ملفات WAV بقارئ صغير خاص فيها: PCM بعمق 8/16/24/32 بت وfloat بعمق 32/64). و`--help` لكل أداة يشتغل ولو ما ثبّت شي.

## الاستعمال

قل لـClaude: «شِل الخلفية الخضراء من هذا الشيت»، «سوّ لي منحنى خفض للموسيقى لهذا التعليق الصوتي بـ30 فريم»، «وين الفراغ في هذا الفيديو؟». أو شغّل السكربتات بنفسك:

```
python scripts/key_decontam.py SHEET_IMAGE OUT_DIR           # OUT_DIR/keyed_sheet.png + obj_00.png ...
python scripts/key_decontam.py --check keyed_a.png keyed_b.png
python scripts/duck_curve.py --fps 25 SPEECH.wav OUT.json
python scripts/blank_beats.py --bg '#FFF8EF' VIDEO.mp4
```

### key-decontam
الطريقة: تقدير لون الخلفية الحقيقي من البكسلات الخضراء القوية؛ ألفا من «هيمنة الأخضر» (g ناقص الأكبر من r وb) فتنجو الخضرة الباهتة مثل النباتات والكتب؛ فصل لون بكسلات الحواف (`f = (p - (1-a)*bg) / a`)؛ البكسلات الشفافة تأخذ لون أقرب بكسل صلب؛ تُحذف الجزر الصغيرة؛ يُشدّ الماتّ ويُزال الانسكاب على حزام 4 بكسل حول الحدود.
- الخيارات: `--lo` (28)، `--min-island` (1500 بكسل)، `--min-object` (6000 مساحة الصندوق)، `--row-height` (200، يجمّع العناصر في صفوف للترقيم)، `--threshold-pct` (0.5)، `--min-ring` (200)، `--force`.
- `--check` يطبع `ok` أو `FAIL` أو `SKIP` أو `ERR` لكل ملف. رموز الخروج: `0` كل الملفات المحكوم عليها نظيفة، `2` ملف واحد على الأقل `FAIL`، `1` ما أمكن الحكم على شي (كلها SKIP) أو تعذّرت قراءة ملف. التخطّي لا يُحسب نجاحاً أبداً.
- أول سطر يقول إن لون الخلفية *مُقدَّر* من الصورة أو *ASSUMED* (أخضر نقي حين لا توجد منطقة خضراء قوية).

### duck-curve
- `--fps` (25) لازم يطابق فيديوك. الخيارات: `--duck-db` (-11)، `--threshold-db` (-42)، `--hold-ms` (250: الفواصل الأقصر تبقى منخفضة)، `--lookahead-ms` (70)، `--attack` (0.08 ث)، `--release` (0.35 ث)، `--tail-sec` (1)، `--force`.
- الناتج: مصفوفة JSON طولها `ceil(ثواني الصوت × fps) + tail`. اضرب مستوى الموسيقى في قيمة الفريم الحالي.

### blank-beats
- `--bg` لون خلفية فيديوك (الافتراضي `#FFF8EF`). `--tolerance` (40، مسافة لونية)، `--coverage` (0.004، نسبة المحتوى التي تحتها يُعدّ الفريم فارغاً)، `--step` (0.05 ث)، `--size` (حجم التحليل 108x192، أي نسبة)، `--min-run`، `--format json`، `--fail-above SECONDS` (خروج 2)، `--timeout` (600 ث).
- الفريمات تُقرأ من ffmpeg بالتدفق فلا تكبر الذاكرة مع طول الفيديو. فشل ffmpeg خطأ (خروج 1) وليس «0 ثانية فارغة».

## الأمان والحدود

- لا يكتب إلا ما تسمّيه: `key_decontam.py` يكتب `keyed_sheet.png` و`obj_NN.png` في مجلد الإخراج؛ `duck_curve.py` يكتب ملف `.json` واحد؛ `blank_beats.py` و`--check` لا يكتبان شيئاً. **لا أداة تكتب فوق ملف موجود** إلا بـ`--force`، وحتى حينها فقط فوق ملف عادي من النوع نفسه (`.json`) أو أسماء الأداة الثابتة.
- المدخلات لازم تكون ملفات عادية موجودة، فلا يصل لـffmpeg رابط أو بروتوكول. الصور حتى 200 ميغابايت و25 ميغابكسل (الحد يُفحص قبل فك الترميز، فلا يستطيع ملف PNG صغير «قنبلة» أن يستنزف الذاكرة)، وملفات WAV حتى 500 ميغابايت، ومعدل العينة بين 4000 و384000 هرتز، والمنحنى حتى 6 ساعات. مسارات الشبكة (UNC، تبدأ بشرطتين مائلتين) مرفوضة للمدخل والمخرج. ملفات القوائم (`.m3u8` و`.m3u` و`.ffconcat` و`.txt`) تُرفض كفيديو، وffmpeg يعمل بـ`-protocol_whitelist file`.
- **`--force` ضيّق.** لا يكتب عبر رابط رمزي ولا hard link. `duck_curve.py --force` يستبدل فقط ملفاً فارغاً أو مصفوفة JSON من أرقام (الشكل الذي تكتبه الأداة)، فلا يطمس ملف إعدادات `.json`. و`key_decontam.py` لا يكتب فوق صورة المدخل حتى مع `--force`. لا تستعمل `--force` إلا عن قصد؛ والـskills تأمر Claude ألا يستعمله إلا بطلبك الصريح.
- **رموز الخروج:** 0 سليم، 2 نتيجة (فرينج `--check` أو `--fail-above`)، 1 أي خطأ بما فيه خطأ في كتابة الأمر (خروج argparse رقم 2 صار 1 حتى لا تقرأ البوابة الخطأ المطبعي كنتيجة). `--help` يخرج 0. الفشل سطر واحد بلا traceback، والأنبوب المغلق يخرج 1 بصمت. خيارات مثل `--duck-db` لازم تكون أرقاماً محدودة (`nan` و`inf` مرفوضة).
- **ffmpeg يُبحث عنه في PATH فقط**: أي ملف باسم `ffmpeg` في المجلد الحالي لا يُستعمل أبداً.
- الـskills تعتمد مسبقاً سكربت البلجن نفسه فقط (`Bash(python ${CLAUDE_PLUGIN_ROOT}/scripts/<tool>.py *)`). ملفات الميديا بيانات؛ يُطلب من Claude ألا يتبع أي نص داخلها.
- `key-decontam` مبنية لـ**رسومات مسطّحة على أرضية خضراء**. الصور الفوتوغرافية والظلال الناعمة والتدرجات والزجاج خارج ما صُمّمت له. عتبات البكسل (`--min-island` و`--min-object` و`--row-height`) مطلقة وليست نسبية لحجم الصورة: اضبطها للشيتات الصغيرة جداً أو الكبيرة جداً. العناصر الملتصقة أو المتداخلة تخرج كقصّة واحدة.
- `duck-curve` منحنى مستوى وليست ميكس: لا تسوية صوتية ولا sidechain لعدة متحدثين؛ اسمع الناتج. تقرأ WAV فقط (حوّل بـ`ffmpeg -i voice.mp3 voice.wav`)؛ الـWAV المضغوط (ADPCM وA-law) يُرفض ولا يُقرأ خطأً.
- `blank-beats` تقيس اللون فقط: لا تعرف إن كان فريم فيه محتوى ذا معنى، و`--bg` خاطئ يجعل كل الفريمات تبدو ممتلئة.
- جديد في 0.1.3: على ويندوز يُرفض ffmpeg من نوع `.bat`/`.cmd` (استعمل `ffmpeg.exe`)؛ وffmpeg الموجود داخل شجرة المجلد الحالي أو عبر مدخل PATH نسبي لا يُستعمل؛ وملفات WAV العشرية بعينات فوق 1000 تُرفض؛ وأسماء الملفات غير القابلة للطباعة لم تعد توقف `--check`. حدّ معروف: مسار البلجن الذي فيه مسافة يكسر الأمر غير المقتبس في الـskills (ثبّته في مسار بلا مسافة)؛ والباقي في CHANGELOG.
- حدود معروفة في 0.1.2: صور PNG بعمق 16 بت تُقاس على مقياس 8 بت (`>> 8`). الخيار `--size` في `blank_beats.py` يقبل حتى 9999x9999 والفريم الواحد بهذا الحجم نحو 3.6 جيجابايت فأبقِه صغيراً. `duck_curve.py` يقبل 200 مليون عينة كحد أقصى (فريمات x قنوات؛ نحو 69 دقيقة أحادية 48 كيلوهرتز) ويحتاج بعدها نحو 2 إلى 5 جيجابايت ذاكرة: قصّ الملفات الأطول أو اجمع قنواتها. السرعة: حلقة الدكّ بايثون عادية. المسارات: مسارات الشبكة (UNC) تُرفض بالاسم فقط (مع الشرطات المختلطة؛ الأقراص المربوطة لا تُكتشف)؛ NTFS alternate data stream (نقطتان رأسيتان بعد حرف القرص) مرفوض على ويندوز؛ ومجلد المخرج أو أي مجلد فوقه إن كان symlink أو junction يُرفض (السحابة/placeholders لا تُعدّ روابط). الفحص الأخير قبل استبدال ملف بـ`--force` والاستبدال خطوتان فتبقى نافذة صغيرة جداً أمام عملية محلية عدائية تبدّل الهدف فيها. على ويندوز تُنهى شجرة ffmpeg بـ`taskkill /T /F /PID` على PID الذي بدأته الأداة؛ حفيد منفصل في Job آخر قد ينجو. `blank_beats.py` يفتح حاويات الفيديو الشائعة فقط (`-format_whitelist`) وغيرها يُرفض ويلزم تحويله.
- غير مُتحقَّق: بايثون 3.8 إلى 3.13، ولينكس وماك (مسار CI مكتوب لها ولم يشتغل)، وتشغيل الـskills حياً داخل Claude Code بما يتجاوز تشغيلاً واحداً بلا واجهة (انظر CHANGELOG)، وشيتات حقيقية غير العيّنات الاصطناعية في الاختبارات.
